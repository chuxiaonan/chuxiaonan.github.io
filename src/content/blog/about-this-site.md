本站使用 Astro + TypeScript 构建为静态网站。首页地球是手写 Canvas 2D 渲染器（不使用 Three.js），支持拖动旋转、减少动态效果偏好，并在离屏时暂停。默认使用深色主题，可通过按钮切换。博客支持 Markdown 与 RSS，经 GitHub Actions 部署到 GitHub Pages。

This static site is built with Astro + TypeScript. The homepage globe uses a hand-written Canvas 2D renderer (no Three.js), with drag-to-rotate, reduced-motion support and pausing when offscreen. The theme is dark by default with a toggle. The blog supports Markdown and RSS, and the site is deployed to GitHub Pages via GitHub Actions.

标题、日期与标签写在文首，页面上只显示正文。
